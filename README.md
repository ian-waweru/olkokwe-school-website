# Olkokwe Senior School Website

Static one-page site (HTML, CSS, a little JavaScript). No build step.

- Open `index.html` in a browser to preview.
- Photos live in `images/gallery/` (WebP). Keep new photos under ~150 KB, ~900px wide.
- Logo: `images/logo/logo-optimized.jpg`.
- Host free on GitHub Pages or Netlify (publish the repo root).
